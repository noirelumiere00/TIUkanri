# public/ — 大学サーバー公開版（本番）

https://www2.tiu.ac.jp/~s24150034/ で公開している本番バージョンのソースです。

## 構成

- `index.html` … フロントエンド全体（HTML / CSS / JavaScript を1ファイルに内蔵したSPA）
- `api.cgi` … **このリポジトリには含まれていません**。サーバー側で実行されるCGIのため
  公開URLからは取得できません。大学サーバー上の原本からコピーして追加してください。

## リポジトリ内の Flask 版との関係

リポジトリ直下の `app.py` ほかは Colab / ローカル向けの Flask 版です。
この `public/` は大学サーバー（CGI 環境）向けに作り直した別実装で、
データ管理はサーバー側の `api.cgi` が担い、フロントは 2.5 秒間隔のポーリングで同期します。

## 更新の流れ

1. `public/index.html` を編集して PR → `main` へマージ
2. マージ後、大学サーバーへアップロード（FTP / SCP 等）して反映
